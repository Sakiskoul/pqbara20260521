# Post-quantum blockchain migration review data

This repository contains the retrieval, deduplication, screening and synthesis
materials for *Post-Quantum Migration of Blockchain Systems: An Evidence Map of
Layers, Trade-offs, and Design Patterns*.

## Current coverage assessments

The [coverage maps](06_eligibility_and_synthesis/coverage_maps/README.md) provide
the current non-exclusive assessment of the 69 core studies and the decisions
supporting the 29 external comparators in Table 1. They include source locators,
assessment-basis notes and a standard-library Python script that regenerates the
coverage totals. These materials support the manuscript's Table 4 and comparator
rubric. D1–D6 identify the six operational migration domains throughout this set.

The earlier retrieval and exclusive primary-classification files remain in
their existing directories. The non-exclusive map is a separate assessment of
the same core set. Full-text and metadata-based assessments are identified
separately. The manuscript describes the assistance used in their preparation.

## Directory contents

- `01_search_log` contains the search logs.
- `02_database_exports` contains database export materials.
- `03_supplementary_sources` contains contextual source materials.
- `04_deduplication` contains deduplication outputs.
- `05_screening` contains screening materials.
- `06_eligibility_and_synthesis` contains eligibility and evidence-map outputs.

Database exports and published source articles remain subject to their original
providers' access and reuse terms. The new coverage package redistributes coding
and provenance records, not the full texts of the reviewed publications.
